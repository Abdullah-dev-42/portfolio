01 / AI DOCUMENT WORKFLOW

DocuFlow AI

Turn lengthy business PDFs into a clearer list of key points, deadlines, risks, and next steps.

PythonFastAPIREST APIReactpypdfSQLiteGemini API
Inside the project
Problem
Manually finding important points, deadlines, responsibilities, and risks in company documents can take time.
Implemented
PDF upload and text extraction; AI-generated summaries, key points, deadlines, responsibilities, rules, risks, and action items; document history; and action-status updates.
How it works
React sends document requests to a FastAPI backend. Python extracts PDF text with pypdf, requests structured analysis from the Gemini API, and stores document data using SQLite and SQLAlchemy before returning results to the frontend.
My contribution
Built the end-to-end document workflow, connecting the React upload and results interface to the Python API, PDF text extraction, and Gemini analysis.
Limitations
Scanned PDFs need OCR, which is not implemented. AI findings should be checked against the source. Hosted SQLite may not persist across free-host restarts. A full live upload-to-analysis run still needs manual verification.
